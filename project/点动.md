# 点动偏移功能

## 一、设计背景

回目标（`RunAngle_GotoTarget`）需要指定绝对角度，但实际使用中经常需要"在当前角度基础上往某个方向移动一小段距离"。点动偏移功能提供了这种相对移动能力，写一次寄存器即可自动完成"解锁→移动→到达→停止"的完整流程。

## 二、寄存器

| 地址 | 名称 | R/W | 类型 | 说明 |
|------|------|-----|------|------|
| 0x272B | REG_JOG_FWD_X10 | W | uint16 | 开窗方向点动偏移 (0.1°) |
| 0x272C | REG_JOG_REV_X10 | W | uint16 | 关窗方向点动偏移 (0.1°) |

**只写不读**，无需在 `Param_ReadByReg` 添加读路径。

### 用法示例

```
当前角度 = 100 (10.0°)

开窗点动 5.0°:  01 06 27 2B 00 32    → 目标 = 100 + 50 = 150, 发 FWD → 跑到 15.0° → 自动 ESTOP
关窗点动 3.0°:  01 06 27 2C 00 1E    → 目标 = 150 - 30 = 120, 发 REV → 跑到 12.0° → 自动 ESTOP
```

## 三、核心公式

```
开窗点动 (0x272B): s_target_x10 = s_abs_offset_x10 + offset_x10
关窗点动 (0x272C): s_target_x10 = s_abs_offset_x10 - offset_x10

然后调用 RunAngle_GotoTarget()，复用现有的门禁和停止判据。
```

## 四、程序执行链路

### Modbus 写路径

```
上位机发 0x06 写 0x272B 或 0x272C
    │
    ▼
App_Modbus.c: Modbus_HandleWriteSingle()
    │
    ├─ 检测 regAddr == REG_JOG_FWD_X10 (0x272B)
    │   └─ RunAngle_JogFwd(regValue)
    │       ├─ s_target_x10 = s_abs_offset_x10 + offset_x10
    │       └─ RunAngle_GotoTarget()
    │
    ├─ 检测 regAddr == REG_JOG_REV_X10 (0x272C)
    │   └─ RunAngle_JogRev(regValue)
    │       ├─ s_target_x10 = s_abs_offset_x10 - offset_x10
    │       └─ RunAngle_GotoTarget()
    │
    └─ 构造 echo response → Modbus_SendResponse → return
        （不经过 Param_WriteByReg，不写 Flash）
```

### RunAngle_GotoTarget 内部流程

```
RunAngle_GotoTarget()
    │
    ├─ Gate 1: Param_IsCtrlUnlocked()?
    │   NO → MAIN_D 拒绝 + return（无 Modbus 异常，静默拒绝）
    │
    ├─ Gate 2: Param_IsMotorStopped()?
    │   NO → MAIN_D 拒绝 + return
    │
    ├─ 计算距离: dist = s_abs_offset_x10 - s_target_x10
    │
    ├─ dist > +阈值 → 发 REV 转动
    │   └─ s_goto_target_active = true
    │
    ├─ dist < -阈值 → 发 FWD 转动
    │   └─ s_goto_target_active = true
    │
    └─ |dist| ≤ 阈值 → 已在目标位置，不动
```

### 主循环停止检测

```
ESystem_MainLoop() 每 1ms:
    │
    └─ RunAngle_Update()
        │
        └─ if s_goto_target_active:
            ├─ dist = s_abs_offset_x10 - s_target_x10
            ├─ |dist| ≤ 阈值?  → MotorManualIOEvent STOP → s_goto_target_active = false
            └─ 符号翻转?       → MotorManualIOEvent STOP → s_goto_target_active = false
```

### 与回目标的对比

| 维度 | 回目标 (0x2727/0x2728) | 点动偏移 (0x272B/0x272C) |
|------|------------------------|--------------------------|
| 目标值来源 | 用户给出的绝对角度 | 当前角度 ± 偏移量 |
| 数据类型 | int32 (0x10连续写) | uint16 (0x06单写) |
| 门禁 | 解锁 + 停转 | 解锁 + 停转 (完全相同) |
| 停止判据 | 阈值 + 符号翻转 | 阈值 + 符号翻转 (完全相同) |
| Flash 存储 | 不存 | 不存 |
| 持续转动 | `s_goto_target_active` | `s_goto_target_active` (共用同一标志) |

| 文件 | 改动 |

| `App_Params.h` | 新增 `REG_JOG_FWD_X10` (0x272B)、`REG_JOG_REV_X10` (0x272C) |
| `App_RunAngle.h` | 新增 `RunAngle_JogFwd()`、`RunAngle_JogRev()` 声明 |
| `App_RunAngle.c` | 新增两个函数（各 ~5 行，计算目标值 + 调 `RunAngle_GotoTarget`） |
| `App_Modbus.c` | 0x06 写路径拦截两个寄存器，echo response 模式 |

**不改动**：`dev_motor`、`dev_sensor`、`dev_rturn`、`App_FaultHandler`。

## 六、安全边界

1. **必须解锁**：`Param_IsCtrlUnlocked()` 检查 RS485 控制锁
2. **必须停转**：`Param_IsMotorStopped()` 检查电机是否停止
3. **自动停止**：到达目标（阈值内）或越过目标（符号翻转）时自动发 ESTOP
4. **手动中断**：转动中发 ESTOP (0x2720 bit2) 可立即停止
5. **过流保护**：过流触发时 `s_goto_target_active` 仍被清除，不影响仲裁器阻塞
6. **并发互斥**：点动中发新点动/回目标 → 门禁"停转"拒绝（电机正在跑）
