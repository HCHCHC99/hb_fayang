## 二、行为说明

### 2.1 欠压检测关闭（改动 #2/#3）

- 欠压阈值强制 **0mV**：判定条件 `u32BusMv <= 0` 永不成立（母线电压 = ADC电压×分压比 + 400mV 补偿，恒 ≥400mV），**数学上不可能触发**；
- **为什么不用"检测时间 1000000ms"方案**：触发计数 `u8UndervoltageTriggerCount` 是 `uint8_t`（上限 255，对应 1ms 节拍下最多 255ms），无法表达 1000000ms（需改结构体类型，动静大）；阈值置 0 已彻底等效关闭，改动最小；
- Modbus 寄存器 `REG_VOLTAGE_LOWER_LIMIT (0x2715)` 读写仍正常（显示 Flash 里的 21.0V），但**实际不生效**——恢复时无需动 Flash；
- 过压检测不受影响，仍为 v5 方案（1ms 节拍 × 连续 30 次采样，确认窗 ≥29ms）。

### 2.2 LED 电压跌落指示（改动 #1/#4/#5）

```
上电 → PH2 置高(灭)
   → 每次判定(1ms)检查: u32BusVoltageMv 与 22000mV (22V) 比较:
       母线 < 22V → PH2 拉低(亮)
       母线 ≥ 22V → PH2 拉高(灭)
   → GPIO 仅在状态变化时写入(边沿触发, 避免每毫秒重复写寄存器)
```

- **实时跟随**：LED 直接反映"当前母线电压是否低于 22V"，<22V 亮、≥22V 灭，无锁存；
- **响应速度**：判定节拍 1ms，电压穿越 22V 后最迟下一个判定点（≤1ms+EMA滤波延迟）LED 翻转；
- **盲区**：上电后前 120ms（`VOLTAGE_STABLE_DELAY_MS` 稳定延时）不检测，LED 保持初始化状态(灭)；
- **注意区分来源**：过流触发（`dev_sensor.c` 过流告警）也会点亮同一颗 LED（只拉低不拉高）。
  由于电压指示在状态变化时会主动拉高/拉低，两者共用时**后写者生效**：
  - 过流点亮后，若母线电压跨越 22V 引起电压指示翻转，会覆盖过流指示；
  - 电压跌落点亮时 RTT（DEV_VOLTAGE 开启时）有 `LED DIP: bus=xx mV, LED ON/OFF` 日志可区分；
- 电压在 22V 附近抖动时 LED 会跟随闪烁，RTT 每次翻转打印一条日志。

## 三、验证方法

1. 上电后 LED 灭（PH2 高）；
2. RTT 启动日志欠压阈值显示 0：`[APP] Voltage config from Flash: ... lower=0 mV ...`；
3. 母线电压降到 22V 以下 → LED 亮；恢复到 22V 以上 → LED 灭（实时跟随，无锁存）；
4. 每次翻转 RTT（DEV_VOLTAGE 开启时）打印 `LED DIP: bus=xx mV, LED ON/OFF`；
5. 欠压告警/故障位不出现（`REG_FAULT_STATUS` bit6 恒 0）。
