# 关窗过流校准阈值

## 一、设计背景

关窗过流时，系统需要判断当前电机位置是否处于"关窗到底"的正常机械范围内。如果角度偏离了预期的机械极限位置，说明发生了异常堵转（如窗户被异物卡住），应报过流故障而非执行校准。

增加两个角度阈值寄存器，构成一个有效的校准角度区间。关窗过流时，仅当 RAM 实时角度在此区间内，才执行角度校准和关窗基准点重置；否则直接报过流故障。

---

## 二、寄存器

| 寄存器 | 地址 | R/W | 类型 | 默认值 | 说明 |
|--------|------|-----|------|--------|------|
| 关窗过流校准上限 | 0x2729 | R/W | int16 (0.1°) | -10 (-1.0°) | 校准有效角度上限 |
| 关窗过流校准下限 | 0x272A | R/W | int16 (0.1°) | -30 (-3.0°) | 校准有效角度下限 |

存储：Flash 扇区 62-56（`AppParamRecord_t`，与 `0x271C` 关窗极限角度同级）

---

## 三、判断逻辑

```
关窗过流 → 电机停转（RTurn lock + RTURN_LIMIT_REV → Motor_OnRTurnLimit → block_rev）
  │
  ├─ 读取 s_abs_offset_x10（RAM 实时角度）
  │
  ├─ calib_lower ≤ angle ≤ calib_upper ?
  │   YES → 校准（正常关窗到位）
  │     ├─ g_s32HallPulseAccum = 0
  │     ├─ fCurrentAngle = fMinAngle
  │     ├─ u8Calibrated = 1（若未标定）
  │     ├─ RunAngle_OnCalibration()
  │     │     ├─ s_abs_offset_x10 = 0x271C值
  │     │     ├─ s_last_accum = g_s32HallPulseAccum（同步基线）
  │     │     ├─ g_AbsAngle.abs_offset_x10 = 0x271C值
  │     │     └─ Param_Save → Flash 扇区 55
  │     ├─ 不报故障
  │     └─ 仅单向锁定(REV方向) — RTURN_LIMIT_REV
  │
  └─ NO → 过流故障（异常堵转）
        ├─ RealTime_SetFault(FAULT_BIT_OVERCURRENT_REV)
        ├─ RTurn_PublishBidirectionalOvercurrent(1)
        │     ├─ TOPIC_OVERCURRENT_FWD(u8IsActive=1) → Motor_OnOvercurrentFwd → block_fwd += OVERCUR_FWD
        │     └─ TOPIC_OVERCURRENT_REV(u8IsActive=1) → Motor_OnOvercurrentRev → block_rev += OVERCUR_REV
        └─ 双向锁死电机（脉冲不清零、角度不重置、不写 Flash）
```

**注意**：正转(开窗)过流时，同样会触发双向熔断：
```
开窗过流 →
  ├─ RealTime_SetFault(FAULT_BIT_OVERCURRENT_FWD)
  ├─ RTurn_PublishBidirectionalOvercurrent(1) → 双向锁死
  └─ 不校准、不重置角度
```

## 四、代码调用链

```
dev_rturn.c: RTurn_UpdateAngle() / RTurn_HandleOvercurrent()
  │
  ├─ 校准点 1（轮询，首次+重复）：RTurn_UpdateAngle, 主动检查过流 + REV
  ├─ 校准点 2（轮询，仅重复）：RTurn_UpdateAngle, 锁释放重检 + REV
  ├─ 校准点 3（EventBus，首次）：RTurn_HandleOvercurrent, 未校准 + 过流方向判断
  └─ 校准点 4（EventBus，重复）：RTurn_HandleOvercurrent, 已校准 + 过流方向判断
       │
       ├─ FWD(开窗)过流 → RealTime_SetFault(FWD) + RTurn_PublishBidirectionalOvercurrent(1)
       │
       └─ REV(关窗)过流 → RunAngle_TryCalibrate()
             │
             ├─ true  → g_s32HallPulseAccum = 0 → RunAngle_OnCalibration() + 单向锁
             └─ false → RealTime_SetFault(REV) + RTurn_PublishBidirectionalOvercurrent(1) + 双向锁
```

**故障清除**（485指令写 0x2740）：
```
FaultHandler_ClearFault(FAULT_TYPE_OVERCURRENT)
  ├─ Sensor_Device_ClearAlarm()
  ├─ Motor_ClearOvercurrentBlock()
  ├─ RealTime_ClearFault(FAULT_BIT_OVERCURRENT_FWD | FAULT_BIT_OVERCURRENT_REV)
  └─ Publish TOPIC_OVERCURRENT_FWD(u8IsActive=0) + TOPIC_OVERCURRENT_REV(u8IsActive=0)
       → dev_motor: 解除双向 block
```

**关键设计**：`RunAngle_TryCalibrate()` 作为闸门，在所有脉冲清零、角度重置操作之前执行。如果不在范围内，后续的清零和校准全部跳过。

## 六、操作示例

**读取**：
```
01 03 27 29 00 01  → 读上限
01 03 27 2A 00 01  → 读下限
```

**设置**（默认上限=-10 即-1.0°，下限=-30 即-3.0°）：
```
01 06 27 29 FF F6  → 设上限 = -10 (-1.0°)
01 06 27 2A FF E2  → 设下限 = -30 (-3.0°)
```

**阈值与 0x271C 的关系**：
- 0x271C 默认 -20（-2.0°），定义关窗基准点的角度值
- 0x2729/0x272A 定义校准的有效角度范围
- 建议：0x271C 的值落在 [0x272A, 0x2729] 区间内
