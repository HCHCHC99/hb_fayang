# 电流控制逻辑说明

## 一、整体架构（三层结构）

电流/过流控制逻辑分为三层，通过 EventBus 事件总线通信：

```
dev_sensor (电流检测层)
    |
    |-- EventBus 发布 TOPIC_CURRENT_ALARM
    |
    +---> dev_rturn (旋转限位层)  -- 通过 RTurn_OnCurrentAlarm 回调处理
    |
    +---> App_FaultHandler (故障管理层) -- 通过 FaultHandler_OnCurrentAlarm 回调处理
```

> **注意**：dev_motor 层不再直接订阅 TOPIC_CURRENT_ALARM（Motor_OnCurrentAlarm 已禁用）。
> dev_motor 改为订阅 TOPIC_OVERCURRENT_FWD 和 TOPIC_OVERCURRENT_REV，由 dev_rturn 发布。

---

## 二、dev_sensor -- 电流检测层

### 2.1 检测原理

整合板差分运放：VOUT = IP × 0.1 (V)，灵敏度 100mV/A

换算公式：
```
电流(mA) = VOUT(mV) × 10
```

例如：
- VOUT = 0mV   → 电流 = 0mA (零电流)
- VOUT = 100mV → 电流 = 1000mA (1A)
- VOUT = 200mV → 电流 = 2000mA (2A)

### 2.2 过流判定逻辑

使用绝对值比较，带回差：

```
触发阈值 = |Threshold| + |Hysteresis|
释放阈值 = |Threshold| - |Hysteresis|
```

例如：Threshold=2000mA, Hysteresis=200mA
- 触发阈值 = 2200mA (电流超过2200mA触发)
- 释放阈值 = 1800mA (电流低于1800mA释放)

### 2.3 防抖动方法（两种模式可选）

#### 模式A：计数模式 (OVERCURRENT_MODE_SAMPLE_COUNT)

- 连续 N 次采样检测到过流才触发报警
- 连续 M 次采样检测到正常才解除报警
- N 和 M 通过参数 TriggerWindowSize 和 ReleaseWindowSize 配置

#### 模式B：时间窗口模式 (OVERCURRENT_MODE_TIME_WINDOW)

- 持续过流超过 T ms 才触发报警
- 持续正常超过 T ms 才解除报警
- T 通过参数 TriggerWindowMs 和 ReleaseWindowMs 配置

### 2.4 报警发布

触发时发布：
```
EventBus_Publish(TOPIC_CURRENT_ALARM, &stcEvent)
其中 stcEvent.u8IsActive = 1
```

解除时（手动模式不自动发布，自动模式自动发布）：
```
EventBus_Publish(TOPIC_CURRENT_ALARM, &stcEvent)
其中 stcEvent.u8IsActive = 0
```

### 2.5 解除模式

#### 自动解除模式 (OVERCURRENT_CLEAR_AUTO)

电流恢复正常后，窗口通过后自动发布解除事件。

#### 手动解除模式 (OVERCURRENT_CLEAR_MANUAL)（当前默认）

电流恢复正常后，不发布解除事件。报警状态保持，block 保持。
需要通过 Modbus 写 REG_FAULT_STATUS 手动清除。

## 三、dev_motor -- 电机仲裁层

### 3.1 当前设计

`Motor_OnCurrentAlarm` **已禁用**（不再订阅 TOPIC_CURRENT_ALARM）。

改为两个独立回调，分别订阅 dev_rturn 发布的定向过流事件：

| 回调 | 订阅 Topic | 动作 |
|------|-----------|------|
| `Motor_OnOvercurrentFwd` | TOPIC_OVERCURRENT_FWD | u8IsActive=1 → block_fwd += DEV_ID_OVERCUR_FWD；u8IsActive=0 → 移除 |
| `Motor_OnOvercurrentRev` | TOPIC_OVERCURRENT_REV | u8IsActive=1 → block_rev += DEV_ID_OVERCUR_REV；u8IsActive=0 → 移除 |

### 3.2 双向熔断机制

任何方向发生过流故障时，dev_rturn **同时发布两个方向的过流事件**：

```
FWD过流 → RealTime_SetFault(FAULT_BIT_OVERCURRENT_FWD)
        → Publish TOPIC_OVERCURRENT_FWD(u8IsActive=1) → block_fwd
        → Publish TOPIC_OVERCURRENT_REV(u8IsActive=1) → block_rev
        → 电机双向锁死

REV过流(角度异常) → RealTime_SetFault(FAULT_BIT_OVERCURRENT_REV)
                  → Publish 双向 → 电机双向锁死
```

### 3.3 SetAllow block 检查

`Motor_CmdList_SetAllow` 入口处检查对应方向 block 队列：
- block 非空 → 拒绝写入 allow → 该方向无法响应新指令
- block 为空 → 正常写入

确保 block 和 allow 永远不会同时非空。

### 3.4 手动清除接口

`Motor_ClearOvercurrentBlock()`：从 block_fwd 移除 DEV_ID_OVERCUR_FWD（保留作为双保险）。

## 四、dev_rturn -- 旋转限位层

### 4.1 过流事件处理

收到 TOPIC_CURRENT_ALARM 事件 (u8IsActive=1)：

1. `RTurn_OnCurrentAlarm` 回调触发
2. 遍历设备管理器找到 RTurn 设备
3. 调用 `RTurn_HandleOvercurrent` 处理

### 4.2 RTurn_HandleOvercurrent 处理逻辑

读取电机仲裁器的期望方向，按方向分别处理：

#### 情况A：期望方向为正转（开窗）

- 未校准：锁正转方向 + 设 FAULT_BIT_OVERCURRENT_FWD + 双向发布过流事件
- 已校准：锁正转方向 + 设 FAULT_BIT_OVERCURRENT_FWD + 双向发布过流事件

#### 情况B：期望方向为反转（关窗）

读取 RAM 实时角度 (s_abs_offset_x10)，与校准阈值比较：

| 寄存器 | 地址 | 默认值 | 说明 |
|--------|------|--------|------|
| 校准上限 | 0x2729 | -10 (-1.0°) | 角度 ≥ 此值 → 校准 |
| 校准下限 | 0x272A | -30 (-3.0°) | 角度 ≤ 此值 → 校准 |

**范围内**（calib_lower ≤ angle ≤ calib_upper）：
- 执行校准：脉冲清零、角度归位到 minAngle
- 未校准状态 → u8Calibrated = 1
- RunAngle_OnCalibration()：RAM/Flash 同步为 0x271C 值
- **不报故障**

**范围外**：
- RealTime_SetFault(FAULT_BIT_OVERCURRENT_REV)
- RTurn_PublishBidirectionalOvercurrent(1)：双向封锁电机
- 脉冲不清零、角度不重置、不写 Flash

范围检查由 RunAngle_TryCalibrate() 实现（见 App_RunAngle.c）。

### 4.3 过流后的影响

无论校准成功还是报故障，都会：
- 发布 TOPIC_RTURN_LIMIT 事件 → Motor_OnRTurnLimit → block 对应方向
- 设置 lock 状态，防止重复处理

### 4.4 轮询检测机制

在 RTurn_UpdateAngle 中，每次更新都检查：

```
如果（未锁定 AND 期望方向有效 AND 限位未触发）
  那么：读取传感器过流报警状态
    如果过流 → 根据方向处理（校准或报故障）
```

为什么需要轮询？
- 过流持续期间，dev_sensor 不会重复发布事件
- 仲裁器可能已将方向变为 STOP
- 需要持续检查过流状态

### 4.5 方向切换释放

当期望方向变为锁定的相反方向时：
- 释放旧锁
- 如果仍然过流 → 检查新方向 → 重新锁定新方向

### 4.6 角度积分与锁定行为

- 反转锁定：忽略角度积分，角度冻结在 minAngle
- 正转锁定：允许角度积分，直到电机停止

## 五、App_FaultHandler -- 故障管理层

### 5.1 故障位定义

```
FAULT_BIT_OVERVOLTAGE      = bit0  (0x0001)  -- 过压
FAULT_BIT_OVERCURRENT_FWD  = bit1  (0x0002)  -- 正转(开窗)过流
FAULT_BIT_OVERCURRENT_REV  = bit2  (0x0004)  -- 反转(关窗)过流
FAULT_BIT_UNDERVOLTAGE     = bit6  (0x0040)  -- 欠压
```

### 5.2 过流故障设置

dev_rturn 层在检测到过流时直接调用 RealTime_SetFault()，FaultHandler 通过 TOPIC_CURRENT_ALARM 做冗余记录。

### 5.3 故障清除流程（手动模式）

Modbus 写 REG_FAULT_STATUS (0x2740) → FaultHandler_ClearFault(FAULT_TYPE_OVERCURRENT)：

```
1. Sensor_Device_ClearAlarm()
   → 清除传感器报警状态

2. Motor_ClearOvercurrentBlock()
   → 直接移除 block_fwd 中的 DEV_ID_OVERCUR_FWD（双保险）

3. RealTime_ClearFault(FAULT_BIT_OVERCURRENT_FWD | FAULT_BIT_OVERCURRENT_REV)
   → 清除双向故障位

4. 发布双向释放事件：
   EventBus_Publish(TOPIC_OVERCURRENT_FWD, u8IsActive=0)
   EventBus_Publish(TOPIC_OVERCURRENT_REV, u8IsActive=0)
   → Motor_OnOvercurrentFwd: 移除 block_fwd 中的 DEV_ID_OVERCUR_FWD
   → Motor_OnOvercurrentRev: 移除 block_rev 中的 DEV_ID_OVERCUR_REV
```

## 六、关键设计要点

### 6.1 双向熔断

过流故障触发时，同时封锁正转和反转两个方向。
清除故障时，同时解除两个方向的封锁。
确保故障状态下电机完全不可动。

### 6.2 校准与故障的区分

关窗过流时：
- 角度在阈值内 → 正常关窗到位 → 校准 → 不报故障，单向锁定
- 角度在阈值外 → 异常堵转 → 报故障，双向锁定

### 6.3 正转 vs 反转过流行为对比

| 方向 | dev_rturn 行为 | 故障位 | 电机封锁 |
|------|---------------|--------|---------|
| 正转(开窗)过流 | 锁定 + 报故障 | FAULT_BIT_OVERCURRENT_FWD | 双向锁 |
| 反转(关窗)过流(范围内) | 锁定 + 校准 | 不触发 | 单向锁(REV) |
| 反转(关窗)过流(范围外) | 锁定 + 报故障 | FAULT_BIT_OVERCURRENT_REV | 双向锁 |

### 6.4 事件轮询 vs 事件驱动

dev_rturn 同时使用两种方式检测过流：
- 事件驱动：通过 TOPIC_CURRENT_ALARM 回调
- 轮询检测：每次 Update 时主动读取传感器报警状态

原因：过流持续期间不会重复发布事件，仲裁器状态可能变化。

### 6.5 阻塞锁汇总

| 设备ID | 阻塞队列 | 触发条件 | 触发源 | 清除方式 |
|--------|---------|---------|--------|---------|
| DEV_ID_OVERCUR_FWD | block_fwd | FWD过流故障 → TOPIC_OVERCURRENT_FWD(u8IsActive=1) | Motor_OnOvercurrentFwd | 手动清故障 → u8IsActive=0 |
| DEV_ID_OVERCUR_REV | block_rev | REV过流故障 → TOPIC_OVERCURRENT_REV(u8IsActive=1) | Motor_OnOvercurrentRev | 手动清故障 → u8IsActive=0 |
| DEV_ID_RTURN_FWD | block_fwd | RTurn 检测到正转限位 → RTURN_LIMIT_FORWARD(u8IsActive=1) | Motor_OnRTurnLimit | 方向切换为 REV 时释放 |
| DEV_ID_RTURN_REV | block_rev | RTurn 检测到反转限位 → RTURN_LIMIT_REVERSE(u8IsActive=1) | Motor_OnRTurnLimit | 方向切换为 FWD 时释放 |
| DEV_ID_IO_FWD | block_fwd | IO STOP 指令 / 初始化 | Motor_OnManualIO | IO FWD 指令移除 |
| DEV_ID_IO_REV | block_rev | IO STOP 指令 / 初始化 | Motor_OnManualIO | IO REV 指令移除 |

### 6.6 手动清除 vs 自动清除

| 模式 | 电流恢复后行为 | 适用场景 |
|------|---------------|---------|
| 自动清除 | 自动解除报警 + 自动移除 block | 需要自动恢复的场景 |
| 手动清除 | 报警保持 + block 保持 | 需要人工确认的场景（当前默认） |
