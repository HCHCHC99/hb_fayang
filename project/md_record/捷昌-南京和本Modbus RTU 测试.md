## 三、通信基础测试

### TC-001 心跳包（定向查询）

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证设备在线且通信正常 |
| 前置条件 | 设备已上电，RS-485 连接正常，设备地址为 01 |
| 测试步骤 | 发送：`01 03 27 1F 00 01 BF 78` |
| 预期结果 | 回令：`01 03 02 00 01 79 84`（返回的 0x0001 等于设备地址 01） |
| 备注 | 日常在线监测推荐使用定向查询。若设备地址不是 01，回令中的数据部分为实际设备地址 |

### TC-002 心跳包（广播查询）

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证广播查询功能 |
| 前置条件 | 总线上至少有一台设备 |
| 测试步骤 | 发送：`00 03 27 1F 00 01 BE A9` |
| 预期结果 | 总线上所有从机同时回复，可能产生电平冲突 |
| 备注 | 仅适用于快速验证是否有设备在线，日常监测不建议使用 |

### TC-003 CRC 校验

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证 CRC 错误时设备不响应 |
| 前置条件 | 设备已上电 |
| 测试步骤 | 发送故意错误的 CRC，如：`01 03 27 1F 00 01 00 00`（CRC 应为 `BF 78`，此处用 `00 00` 代替） |
| 预期结果 | 设备不响应 |

### TC-102 开窗（正常工况、已校准）

|------|------|
| 测试目的 | 验证开窗运转及自动停止 |

### TC-104 关窗（正常到位）

## 五、关窗基准点测试

### TC-201 设关窗基准点并保存

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证手动设定关窗基准点 |
| 前置条件 | 设备已上电 |
| 测试步骤 | 1. 将电机转到目标位置；2. 发送：`01 06 27 25 00 00 92 B5` |
| 预期结果 | 回令：`01 06 27 25 00 00 92 B5`（回显）。读 0x2721/0x2722 应返回 0x271C 的值（默认 -20，即 -2.0 度） |

### TC-202 读实时角度

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证读取基于关窗基准点的实时位置 |
| 前置条件 | 已设关窗基准点 |
| 测试步骤 | 发送：`01 03 27 21 00 02 9E B5` |
| 预期结果 | 回令（示例，位置=-2.0 度）：`01 03 02 04 FF FF FF EC BA 6A`。将 4 字节数据 `FF FF FF EC` 拼为 int32（0xFFFFFFEC = -20），除以 10 得 -2.0 度 |
| 备注 | 位置值随电机转动实时变化。若为其他角度，数据部分相应变化 |

### TC-204 回到关窗基准点

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证电机自动回到关窗基准点 |
| 前置条件 | 已设关窗基准点，当前位置不在基准点上，已解锁，电机停转 |
| 测试步骤 | 发送：`01 06 27 25 00 01 53 75` |
| 预期结果 | 回令：`01 06 27 25 00 01 53 75`（回显）。电机转动到关窗基准点角度，进入停止阈值范围后自动急停 |

### TC-205 回关窗基准点（未解锁）

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证安全门禁：未解锁时拒绝回基准点 |

| 测试步骤 | 直接发送：`01 06 27 25 00 01 53 75` |
| 预期结果 | 指令被拒绝，电机不动作。回令仍为回显，但固件内部拒绝执行 |

### TC-206 回关窗基准点（电机运转中）

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证安全门禁：运转中拒绝回基准点 |

| 测试步骤 | 电机运转时发送：`01 06 27 25 00 01 53 75` |
| 预期结果 | 指令被拒绝，不影响当前运转。回令仍为回显，但固件内部拒绝执行 |

### TC-207 转到目标角度

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证转到指定角度功能 |
| 前置条件 | 已设关窗基准点，已解锁，电机停转 |
| 测试步骤 | 发送转到 88.0 度（值=880=0x0370，int32）：`01 10 27 27 00 02 04 03 70 00 00 0E 3F` |
| 预期结果 | 成功回令：`01 10 27 27 00 02 FB 77`。电机转动到接近 88.0 度，进入停止阈值范围后自动急停 |

### TC-208 转到目标角度（未解锁）

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证安全门禁：未解锁时拒绝回目标并返回异常码 |
| 前置条件 | 控制处于上锁状态 |
| 测试步骤 | 发送：`01 10 27 27 00 02 04 03 70 00 00 0E 3F` |
| 预期结果 | 失败回令：`01 90 04 4D C3`（异常码 04 = SLAVE DEVICE FAILURE）。目标值不被覆盖，电机不动作 |

### TC-209 停止阈值设置与生效

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证停止阈值的读写、热重载以及阈值停止行为 |
| 背景说明 | 停止阈值用于两方面：一、补偿停止过冲——电机依靠直接切断驱动停止（无缓停），存在惯性滑行，系统在当前角度进入阈值范围时提前发出停止指令，利用惯性自然趋近目标；二、避免无效微调——位置检测存在精度限制，若当前角度已在阈值范围内则直接判定为已到位，不再转动。停止阈值越大，提前停止的余量越大，用户可根据实际过冲量调整。 |
| 前置条件 | 设备已上电，已设关窗基准点 |
| 测试步骤 | 1. 读当前阈值：`01 03 27 26 00 01 6F 75`，预期回令（默认1）：`01 03 02 00 01 79 84`；2. 设新阈值=2.0 度（值=20）：`01 06 27 26 00 14 62 BA`，回令回显；3. 执行回到关窗基准点（`01 06 27 25 00 01 53 75`），观察停止时的角度与目标角度的偏差；4. 将电机移动到目标角度附近（偏差小于阈值），再次发送回基准点指令，观察电机是否不再转动 |
| 预期结果 | 阈值可正确读写，修改后立即生效（热重载）。回令均为回显。步骤3：电机在进入阈值范围内停止，实际停止位置与目标角度的偏差小于设定的阈值。步骤4：若当前角度已在阈值范围内，电机不转动，直接判定为已到位 |

### TC-209a 停止阈值——已在阈值内不转动

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证当前位置已在停止阈值范围内时，回基准点不会触发转动 |
| 前置条件 | 已设关窗基准点，当前角度距离基准点角度小于停止阈值 |
| 测试步骤 | 1. 确保当前位置已在阈值范围内（可通过回基准点到位后的状态直接测试）；2. 解锁后发送回基准点：`01 06 27 25 00 01 53 75` |
| 预期结果 | 回令回显。电机不转动（因已判定为到位） |

### TC-210 掉电保持（正常流程：急停后断电）

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证关窗基准点掉电后不丢失 |
| 前置条件 | 已设关窗基准点，电机停转 |
| 测试步骤 | 1. 掉电前读已保存位置：`01 03 27 23 00 02 3F 75`，记录回令中的数据；2. 确认电机已停转；3. 设备断电；4. 重新上电；5. 再次读已保存位置：`01 03 27 23 00 02 3F 75` |
| 预期结果 | 掉电前后已保存位置一致 |

### TC-211 掉电保持（异常：运转中直接断电）

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证未发急停直接掉电可能导致基准点偏移 |
| 前置条件 | 电机正在运转中 |
| 测试步骤 | 1. 电机运转时直接断电；2. 重新上电；3. 读当前位置：`01 03 27 21 00 02 9E B5` |
| 预期结果 | 关窗基准点可能存在偏差，与掉电前的实际位置不一致 |
| 备注 | 这是异常操作场景，用于验证警告的正确性。偏移后需重新执行关窗过流校准恢复 |

## 七、故障处理测试

### TC-401 读取故障状态

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证故障状态寄存器读取 |
| 前置条件 | 设备已上电 |
| 测试步骤 | 发送：`01 03 27 40 00 01 8F 6A` |
| 预期结果 | 正常无故障时回令：`01 03 02 00 00 B8 44`。各故障回令示例：过压(bit0)：`01 03 02 00 01 79 84`；开窗过流(bit1)：`01 03 02 00 02 39 85`；关窗过流(bit2)：`01 03 02 00 04 B9 87`；欠压(bit6)：`01 03 02 00 40 B9 B4` |
| 备注 | bit1 和 bit2 同时发生则为 0x0006 |

### TC-402 清除故障

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证清除故障指令 |
| 前置条件 | 当前有故障记录 |
| 测试步骤 | 发送：`01 06 27 40 00 00 82 AA` |
| 预期结果 | 回令：`01 06 27 40 00 00 82 AA`（回显）。故障位清零，方向锁定解除。再次读故障应返回 `01 03 02 00 00 B8 44` |

### TC-403 关窗过流（阈值区间内）

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证正常关窗到位时的校准流程 |
| 前置条件 | 正常工况，角度在 [0x272A, 0x2729] 区间内 |
| 测试步骤 | 1. 解锁：`01 06 27 20 00 01 43 74`；2. 关窗：`01 06 27 20 00 20 83 6C`；3. 等待堵转过流后读故障：`01 03 27 40 00 01 8F 6A` |
| 预期结果 | 电机停转；读故障应无新增故障位（正常为 `01 03 02 00 00 B8 44`）；读当前位置（`01 03 27 21 00 02 9E B5`）可获取角度值 |
| 备注 | 关窗方向被单向锁定，发开窗指令可解除 |

### TC-404 关窗过流（阈值区间外）

| 项目 | 内容 |
|------|------|
