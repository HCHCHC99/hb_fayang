# 启停消隐（短暂关电流采样）

## 背景

电机从停止切换到正转或反转时，启动瞬间会产生较大的浪涌电流尖峰。此时 `dev_sensor` 的过流检测如果正常工作，很容易将启动浪涌误判为过流，触发故障报警，导致电机被错误锁住。

**物理过程**：电机启动 → H 桥换相 → 短时大电流 → 消隐窗口内恢复至正常电流。

两个方向的启动都需要消隐，但由于正转（开窗）和反转（关窗）的负载特性不同，消隐时长各自独立配置。

## 设计思路

### 核心思想

在仲裁系统**刚切换到正转或反转**时，关闭 `dev_sensor` 的过流检测一段可配置的时长，给电机启动浪涌一个"消隐窗口"。消隐到期后自动恢复过流检测。

### 两个方向独立消隐

| 方向 | 宏 | 默认值 | 说明 |
|------|-----|--------|------|
| 正转（开窗/FWD） | `MOTOR_FORWARD_BLANK_MS` | 50ms | 开窗启动浪涌较小，消隐时间短 |
| 反转（关窗/REV） | `MOTOR_REVERSE_BLANK_MS` | 2000ms | 关窗启动浪涌较大，且关窗到位后正常堵转也会产生大电流 |

### 为什么不是每次调用都重置定时器

仲裁系统选中某个方向后，`Motor_OnArbitrationFwd()` / `Motor_OnArbitrationRev()` 约每 10ms 被重复调用一次。如果每次调用都重置定时器，消隐就永远不会结束。因此引入 `s_u8LastArbWasFwd` / `s_u8LastArbWasRev` 记录"上一次仲裁结果是否已经是该方向"，**只在首次进入时**启动消隐定时器。

### 方向切换时的互锁

从一个方向切换到另一个方向时，旧方向的消隐立即取消，新方向的消隐开始：

- 正转 → 反转：清除正转消隐 → 启动反转消隐
- 反转 → 正转：清除反转消隐 → 启动正转消隐
- 任意方向 → 停止：清除两个方向的消隐

## 完整调用链

### 写入侧 — dev_motor

```
主循环 → DeviceManager 调度
    │
    ├─ Motor_Update()                              [每次主循环调用]
    │   ├─ 正转消隐定时器到期?
    │   │   g_u8MotorForwardBlankActive && nbDelay_IsComplete() → 清零
    │   ├─ 反转消隐定时器到期?
    │   │   g_u8MotorReverseBlankActive && nbDelay_IsComplete() → 清零
    │   │
    │   └─ 每50ms仲裁一次:
    │       └─ Motor_ArbitrationDecision()
    │           │
    │           ├─ Motor_OnArbitrationFwd()
    │           │   ├─ 首次进入? → 启动 MOTOR_FORWARD_BLANK_MS + 标志=1
    │           │   ├─ s_u8LastArbWasFwd = 1
    │           │   └─ 清除反转消隐状态
    │           │
    │           └─ Motor_OnArbitrationRev()
    │               ├─ 清除正转消隐状态
    │               ├─ 首次进入? → 启动 MOTOR_REVERSE_BLANK_MS + 标志=1
    │               └─ s_u8LastArbWasRev = 1
    │
    └─ Motor_OnArbitrationStop()
        └─ 清除正转 + 反转消隐状态
```

### 读取侧 — dev_sensor

```
主循环 → DeviceManager 调度
    │
    └─ Sensor_Device_Update()                      [每次主循环调用]
        ├─ Sensor_ReadFromAdc()                    [正常执行，不受影响]
        ├─ Sensor_CalcCurrent()                    [正常执行，不受影响]
        └─ Sensor_CheckOvercurrent()
            ├─ g_u8MotorForwardBlankActive?
            │   YES → return                       [正转消隐: 跳过]
            ├─ g_u8MotorReverseBlankActive?
            │   YES → return                       [反转消隐: 跳过]
            └─ 两个都 NO → 正常执行过流判断逻辑
```

**关键**：消隐期间 ADC 读取和电流计算照常进行，Modbus 上报的电流值不受影响，只有过流报警判断被跳过。

### 时序示意

```
[停止] ──仲裁→ [正转消隐 50ms] ──到期→ [正转运行+过流正常]
                     │                          │
             过流检测跳过             如果过流→正常报警+阻塞

[停止] ──仲裁→ [反转消隐 2000ms] ──到期→ [反转运行+过流正常]
                     │                          │
             过流检测跳过         如果关窗到位堵转过流→正常报警+阻塞
```

## 代码实现

### 涉及文件

| 文件 | 改动 |
|------|------|
| `dev_motor.h` | 定义消隐时长宏 `MOTOR_FORWARD_BLANK_MS` (50U)、`MOTOR_REVERSE_BLANK_MS` (2000)，声明两个全局标志位 |
| `dev_motor.c` | 管理两个方向的消隐状态机：启动定时器、方向切换互锁、轮询到期 |
| `dev_sensor.c` | 在 `Sensor_CheckOvercurrent` 入口检查两个消隐标志，任一为真则 return |

跨模块通信方式：`dev_motor.c` 定义全局变量，`dev_sensor.c` 内通过函数级 `extern` 声明引用，由链接器解析。

### dev_motor.h — 宏定义与外部声明

```c
// ========== 正转消隐配置 ==========
#define MOTOR_FORWARD_BLANK_MS     (50U)     // 正转消隐时长（ms）

// ========== 反转消隐配置 ==========
#define MOTOR_REVERSE_BLANK_MS     (2000)    // 反转消隐时长（ms）

// ========== 消隐全局标志位 ==========
extern volatile uint8_t g_u8MotorForwardBlankActive;
extern volatile uint8_t g_u8MotorReverseBlankActive;
```

### dev_motor.c — 状态变量定义

```c
// ========== 反转消隐变量 ==========
static uint8_t s_u8LastArbWasRev = 0;
static NonBlockingDelay_t s_stcReverseBlankTimer;
volatile uint8_t g_u8MotorReverseBlankActive = 0;

// ========== 正转消隐变量 ==========
static uint8_t s_u8LastArbWasFwd = 0;
static NonBlockingDelay_t s_stcForwardBlankTimer;
volatile uint8_t g_u8MotorForwardBlankActive = 0;
```

### dev_motor.c — 首次进入正转时启动消隐

```c
__weak void Motor_OnArbitrationFwd(MotorDevice_t* motor, float duty) {
    (void)motor;
    // 只在刚切换到正转时启动消隐
    if (!s_u8LastArbWasFwd) {
        nbDelay_Init(&s_stcForwardBlankTimer, MOTOR_FORWARD_BLANK_MS);
        nbDelay_Start(&s_stcForwardBlankTimer);
        g_u8MotorForwardBlankActive = 1;
    }
    s_u8LastArbWasFwd = 1;
    // 离开反转 → 取消反转消隐
    s_u8LastArbWasRev = 0;
    g_u8MotorReverseBlankActive = 0;
    // ... GPIO 控制代码（PHU/PHV）
}
```

### dev_motor.c — 首次进入反转时启动消隐

```c
__weak void Motor_OnArbitrationRev(MotorDevice_t* motor, float duty) {
    (void)motor;
    // 离开正转 → 取消正转消隐
    s_u8LastArbWasFwd = 0;
    g_u8MotorForwardBlankActive = 0;
    // 只在刚切换到反转时启动消隐
    if (!s_u8LastArbWasRev) {
        nbDelay_Init(&s_stcReverseBlankTimer, MOTOR_REVERSE_BLANK_MS);
        nbDelay_Start(&s_stcReverseBlankTimer);
        g_u8MotorReverseBlankActive = 1;
    }
    s_u8LastArbWasRev = 1;
    // ... GPIO 控制代码（PHU/PHV）
}
```

### dev_motor.c — 停止时清除两个方向的消隐

```c
__weak void Motor_OnArbitrationStop(MotorDevice_t* motor) {
    (void)motor;
    s_u8LastArbWasFwd = 0;
    g_u8MotorForwardBlankActive = 0;
    s_u8LastArbWasRev = 0;
    g_u8MotorReverseBlankActive = 0;
    // ... GPIO 控制代码
}
```

### dev_motor.c — 定时器到期自动清除

```c
// Motor_Update 中，每次主循环都会检查:
if (g_u8MotorForwardBlankActive && nbDelay_IsComplete(&s_stcForwardBlankTimer)) {
    g_u8MotorForwardBlankActive = 0;
}

if (g_u8MotorReverseBlankActive && nbDelay_IsComplete(&s_stcReverseBlankTimer)) {
    g_u8MotorReverseBlankActive = 0;
}
```

### dev_sensor.c — 消隐期间跳过过流检测

```c
static void Sensor_CheckOvercurrent(Sensor_Device_t* pstcDev) {
    if (!pstcDev) return;

    extern volatile uint8_t g_u8MotorForwardBlankActive;
    extern volatile uint8_t g_u8MotorReverseBlankActive;
    if (g_u8MotorForwardBlankActive || g_u8MotorReverseBlankActive) {
        return;  // 任一方向消隐中 → 跳过过流检测
    }

    // ... 原有过流检测逻辑（SampleCount / TimeWindow 两种模式）
}
```

## 方向切换行为表

| 切换路径 | 正转消隐 | 反转消隐 |
|----------|:---:|:---:|
| 停止 → 正转 | **启动 50ms** | — |
| 停止 → 反转 | — | **启动 2000ms** |
| 正转 → 反转 | 立即取消 | **启动 2000ms** |
| 反转 → 正转 | **启动 50ms** | 立即取消 |
| 任意 → 停止 | 立即取消 | 立即取消 |
| 消隐到期 | 自动恢复 | 自动恢复 |

## TickTimer 依赖

`NonBlockingDelay_t` 的非阻塞延时依赖 `tickTimer_Update()` 每 1ms 被调用一次来推进 tick 计数。消隐定时器的到期判断基于此机制。

## 注意事项

1. **消隐期间 ADC 读取和电流计算照常进行**，Modbus 上报的电流值不受影响，只有过流报警判断被跳过。
2. **两个方向独立消隐**，正转和反转使用各自的宏和定时器，互不干扰。
3. **方向切换立即处理**：从一个方向切到另一个方向时，旧方向消隐立即取消，新方向消隐立即启动。
4. **停止时全部清除**：电机停止时两个方向的消隐状态全部清零。
5. **非阻塞**：消隐定时器基于 `TickTimer` 的非阻塞延时，不会卡住主循环。
6. **调整消隐时长**：修改 `dev_motor.h` 中的 `MOTOR_FORWARD_BLANK_MS` 或 `MOTOR_REVERSE_BLANK_MS` 宏即可。
