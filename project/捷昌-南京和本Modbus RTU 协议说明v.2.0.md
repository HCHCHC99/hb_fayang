# 捷昌-南京和本Modbus RTU 协议说明 v2.0

---

## 一、程序逻辑

### 1.1 控制逻辑

设备上电后，根据现场实际情况进入正常工况或检修工况。

#### 正常工况

执行器已安装合页并带负载运行。关窗到位时合页撞击门框产生堵转过流，系统利用该物理信号自动检测到位。正常工况下的完整流程如下：

**第一步：上电后先关窗，完成角度校准与基准点设定**

设备上电后，应先执行关窗操作。电机驱动窗户向关闭方向转动，直至合页撞击门框产生堵转过流。此时系统会检查当前角度（通过 0x2721/0x2722 读取）是否落在校准阈值区间内（由 0x2729 和 0x272A 定义，详见第六章）：

- 角度在阈值区间内：判定为正常关窗到位。系统自动将关窗基准点校准到 0x271C（关窗极限角度）定义的值并保存，同时使能角度校准功能。此后角度校准功能处于有效状态，开窗时系统能够依据实时角度自动判断是否到达开窗极限角度。
- 角度超出阈值区间：判定为异常堵转（如窗户被异物卡住）。系统不会校准关窗基准点，也不会使能角度校准功能，同时在故障寄存器（0x2740）中记录关窗过流故障。此时需清除故障并排除异常后重新关窗。

**第二步：角度校准使能后，开窗可自动停止**

关窗校准成功后，角度校准功能已使能。此时发送开窗指令，电机驱动窗户向打开方向转动，系统通过 0x2721/0x2722 实时追踪角度变化。当到达 0x271D（开窗极限角度）时自动停止，无需人工干预。

**第三步：后续关窗自动维护校准**

之后的每次关窗操作，当堵转过流触发且角度在阈值区间内时，系统都会自动重新校准关窗基准点并再次使能角度校准，以此消除长期运行可能产生的累积误差。

> 【重要】上电后必须先执行关窗操作，且关窗过流时角度必须在阈值区间内，才能完成角度校准并使能角度校准功能。若跳过关窗直接开窗，由于角度校准功能尚未使能，系统无法追踪角度，开窗将不会自动停止，仅能通过急停指令或手动干预来停止电机。

#### 检修工况

执行器与合页分离，不带负载运行，无法产生堵转过流信号。

- 开窗和关窗均不会触发堵转过流，因此不会进行关窗基准点校准，角度校准功能也无法使能。
- 开窗和关窗均不会自动停止，需依靠急停指令或手动干预。
- 检修结束后可发送"回到关窗基准点"指令，使执行器回到适合与合页装配的位置。

#### 通用规则

| 规则 | 说明 |
|------|------|
| 回到关窗基准点 | 任何工况下都可发送，电机自动转动到关窗基准点角度，到达阈值范围内自动停止。 |
| 转到目标角度 | 基于关窗基准点，可发送指令转到任意角度，到达阈值范围内自动停止。 |
| 急停 | 任何运行过程中都可发送，电机立即停止。 |
| 掉电 | 关窗基准点掉电后不丢失，重新上电可继续使用。但掉电前必须先发送急停指令使电机完全停止，若电机仍在转动时直接断电，关窗基准点可能产生偏移，导致重新上电后位置不准确。 |

### 1.2 过流方向锁

系统具备过流方向锁止保护功能：一旦电机在某个运动方向上发生堵转过流，该方向将被锁止，无法继续朝该方向转动。需先发反方向指令使电机朝反方向运动，方可解除锁止。

- 关窗方向过流（角度在阈值区间内）：正常到位，执行关窗基准点校准并使能角度校准，仅锁定关窗方向。
- 关窗方向过流（角度超出阈值区间）：异常堵转，报过流故障，同时锁定开窗和关窗两个方向。
- 开窗方向过流：异常工况，报过流故障，同时锁定两个方向。

### 1.3 故障处理

系统支持以下故障类型：

| 故障类型 | 触发条件 | 处理方式 |
|---------|---------|---------|
| 过压 | 电压大于 0x2714 阈值 | 记录故障位 bit0，电机停转。电压恢复正常后发送清除故障指令即可恢复。 |
| 欠压 | 电压小于 0x2715 阈值 | 记录故障位 bit6，电机停转，当前角度自动保存。电压恢复正常后发送清除故障指令即可恢复。 |
| 过流（关窗/阈值区间内） | 关窗堵转，角度在 [0x272A, 0x2729] 区间内 | 正常到位。不记录故障，执行关窗基准点校准并使能角度校准，仅锁定关窗方向。 |
| 过流（关窗/阈值区间外） | 关窗堵转，角度超出 [0x272A, 0x2729] 区间 | 异常堵转。记录故障位 bit2，不校准关窗基准点，双向锁定。需清除故障并排除异物后重新关窗。 |
| 过流（开窗） | 开窗过流 | 异常工况。记录故障位 bit1，双向锁定，需发送清除故障指令。 |

> 任何方向发生过流故障时，开窗和关窗两个方向会同时被锁定。发送清除故障指令后，两个方向自动恢复。

## 四、控制命令寄存器（0x2720）

### 4.1 位定义

| 位 | 值 | 说明 |
|----|-----|------|
| bit0 | 0x0001 | 解锁（控制开启），允许 bit4/bit5 生效。 |
| bit1 | 0x0002 | 上锁（控制关闭），禁止 bit4/bit5。 |
| bit2 | 0x0004 | 急停，无条件执行。 |
| bit3 | 0x0008 | 延时复位。 |
| bit4 | 0x0010 | 开窗（逆时针/正转）。 |
| bit5 | 0x0020 | 关窗（顺时针/反转）。 |

读回值含义：bit4=1 正在正转，bit5=1 正在反转，bit4=bit5=0 已停止。

### 4.2 操作流程

标准操作流程为：先发送解锁指令，再发送开窗或关窗指令，操作完毕后发送上锁指令。

```
解锁 (0x0001)  ->  开窗 (0x0010) 或 关窗 (0x0020)  ->  上锁 (0x0002)
```

### 4.3 安全门禁

回到关窗基准点和转到目标角度共用两道安全门禁：

| 门禁 | 不满足时的行为 |
|------|--------------|
| 需先发送解锁指令（0x2720=0x0001） | 指令被拒绝，不执行任何动作。 |
| 电机必须处于停转状态 | 指令被拒绝，不影响当前正在执行的动作。 |

> 转到目标角度时，门禁检查在更新目标值之前执行。若未解锁或电机正在转动，指令被拒绝并返回异常码，当前目标值不会被覆盖。

## 五、关窗基准点系统

### 5.1 设计概述

设备通过 0x2721/0x2722（int32，单位 0.1 度）提供实时角度读数。该角度基于关窗基准点坐标系，具有以下特性：

- 始终有效：上电后即可读取，无需等待关窗校准。
- 掉电保持：掉电前系统自动保存当前角度，重新上电后自动恢复。
- 高精度：int32 格式，范围约为正负 21 亿度，不会回绕。

此外，通过 0x2723/0x2724 可读取掉电时自动保存的角度值，用于核对或恢复参考。

> 【重要】关窗基准点在掉电后仍然保留，重新上电后可继续使用。但掉电前必须先发送急停指令（0x2720=0x0004）使电机完全停止。若电机仍在转动时直接断电，关窗基准点可能产生位置偏移，导致重新上电后位置不准确，需重新执行关窗校准来恢复。

### 5.2 关窗基准点指令寄存器（0x2725）

| 写入值 | 操作 | 说明 |
|--------|------|------|
| 0x0000 | 设关窗基准点并保存 | 将当前位置设为关窗基准点（值取 0x271C），掉电后不丢失。 |
| 0x0001 | 回到关窗基准点 | 转动到 0x271C 定义的角度。需先解锁且电机处于停转状态。到达停止阈值范围内后自动停止。 |

> 关窗基准点的目标角度值由 0x271C 定义。例如：0x271C = -20 时，关窗基准点对应 -2.0 度。当需要将关窗基准点设置在与原位置差异较大的新位置时（例如设备重新安装或更换应用场景），可先将电机移动到目标位置，再发送 0x0000 指令，系统即将该位置记录为新的关窗基准点，后续操作均以新的基准点为参考。

### 5.3 转到目标角度（0x2727/0x2728）

基于关窗基准点，可发送指令使电机转动到指定的任意角度。到达停止阈值范围内后自动停止。

**写操作**

使用功能码 0x10 一条指令写入目标角度并立即触发转动：

```
01 10 27 27 00 02 04 [LO_H] [LO_L] [HI_H] [HI_L] CRC CRC
```

**读操作**

使用功能码 0x03 读取当前设定的目标角度（返回 4 字节 int32）：

```
01 03 27 27 00 02
```

目标角度为 int32 (0.1 度)。

**示例：转到 88.0 度（880 = 0x0370）**

```
01 10 27 27 00 02 04 03 70 00 00 0E 3F
```

### 5.4 停止阈值（0x2726）

回到关窗基准点和转到目标角度共用停止阈值。电机在接近目标位置时会提前在阈值范围内停止，而非到达精确目标点才停。这样设计有两方面原因：

**一、补偿停止过冲**

电机停止时依靠直接切断驱动而非缓慢减速，因此从发出停止指令到完全静止之间存在惯性滑行。如果等到位置完全等于目标值才停止，电机会因惯性冲过目标点。设置停止阈值使得系统在当前角度与目标角度的差值进入阈值范围内时即发出停止指令，利用惯性滑行自然趋近目标位置。阈值越大，提前停止的余量越大；用户可根据实际过冲量调整此值。

**二、避免无效微调**

位置检测存在一定精度限制，并非每次都能恰好停在精确的目标角度上。如果当前角度已在阈值范围内，说明位置已经足够接近目标，系统判定无需再次转动，直接视为已到位。这避免了因为微小偏差而反复启停电机。

停止阈值的单位为 0.1 度，可设置范围 0~200（即 0~20.0 度），默认值为 1（即 0.1 度）。写入后立即生效，掉电保存。

| 操作 | 指令 | 说明 |
|------|------|------|
| 读取 | `01 03 27 26 00 01` | 返回 uint16，单位为 0.1 度。 |
| 设置 | `01 06 27 26 00 0A` | 设为 1.0 度（值=10），范围 0~200。 |

### 5.5 操作指南

#### 首次使用（安装后）

1. 将电机转动到需要设为关窗基准点的位置（通常为关窗到底的机械极限位置）。
2. 发送指令设关窗基准点并保存：

```
01 06 27 25 00 00
```

完成后，读实时角度（0x2721/0x2722）将得到 0x271C 的值（例如 -20 即 -2.0 度）。

#### 手动更改关窗基准点

当需要将关窗基准点设置在与原位置差异较大的新位置时（例如设备重新安装、更换应用场景或机械结构发生变动），无需修改 0x271C 的值，可直接通过指令将当前物理位置设为新的关窗基准点：

1. 将电机移动到需要设为新关窗基准点的物理位置。
2. 发送指令：

```
01 06 27 25 00 00
```

系统即将当前物理位置记录为关窗基准点，角度值取 0x271C 定义的值。后续所有基于关窗基准点的操作（回基准点、转到目标角度等）均以新的基准点为参考。

> 注意：手动更改关窗基准点后，原有的关窗过流自动校准逻辑不受影响。下次关窗过流且角度在阈值区间内时，系统仍会自动校准关窗基准点。若需要避免自动校准覆盖手动设定的基准点，可适当调整校准角度阈值（0x2729/0x272A）或关窗极限角度（0x271C）。

#### 读取实时角度

通过 0x2721/0x2722 读取基于关窗基准点的实时角度，始终有效，掉电保持：

```
发送: 01 03 27 21 00 02
```

返回 4 字节数据，拼为 int32，除以 10 即为度数。

> 若需读取掉电时自动保存的角度值（用于核对或恢复），可通过 0x2723/0x2724 读取，解析方法相同。

#### 回到关窗基准点

1. 发送解锁指令：

```
01 06 27 20 00 01
```

2. 确认电机已停转。
3. 发送回到关窗基准点指令，电机开始转动：

```
01 06 27 25 00 01
```

4. 到达停止阈值范围内后自动急停。
5. 发送上锁指令：

```
01 06 27 20 00 02
```

#### 转到目标角度

1. 发送解锁指令：

```
01 06 27 20 00 01
```

2. 确认电机已停转。
3. 发送目标角度并触发转动（以转到 88.0 度为例）：

```
01 10 27 27 00 02 04 03 70 00 00 0E 3F
```

4. 到达停止阈值范围内后自动急停。
5. 发送上锁指令：

```
01 06 27 20 00 02
```

## 六、关窗过流校准阈值

### 6.1 设计背景

关窗过流时，系统需判断电机位置是否处于正常的机械范围内。若位置偏离预期范围，说明发生异常堵转（如窗户被异物卡住），应报过流故障而非执行校准。可通过 0x2729 和 0x272A 设置校准有效的角度区间。

### 6.2 寄存器

| 寄存器 | 名称 | R/W | 类型 | 默认值 | 说明 |
|--------|------|-----|------|--------|------|
| 0x2729 | 校准角度上限 | R/W | int16 | -10（-1.0 度） | 校准有效的角度上限。关窗过流时，实时角度低于此值才执行校准。 |
| 0x272A | 校准角度下限 | R/W | int16 | -30（-3.0 度） | 校准有效的角度下限。关窗过流时，实时角度高于此值才执行校准。 |

> 建议：0x271C 的值应落在 [0x272A, 0x2729] 区间内。默认 0x271C=-20 在上限 -10 和下限 -30 之间。

### 6.3 操作示例

**读取校准阈值：**

```
01 03 27 29 00 01    // 读上限
01 03 27 2A 00 01    // 读下限
```

**设置校准阈值：**

```
01 06 27 29 FF F6    // 设上限 = -10 (-1.0 度)
01 06 27 2A FF E2    // 设下限 = -30 (-3.0 度)
```

## 七、故障状态寄存器（0x2740）

### 7.1 故障位定义

| 位 | 值 | 说明 |
|----|-----|------|
| bit0 | 0x0001 | 过压故障。 |
| bit1 | 0x0002 | 正转（开窗）过流故障。 |
| bit2 | 0x0004 | 反转（关窗）过流故障（角度异常）。 |
| bit6 | 0x0040 | 欠压故障（触发时自动保存当前角度）。 |

### 7.2 清除故障

故障排除后，发送清除故障指令即可恢复。清除故障时会自动：

- 清除所有过流故障位。
- 解除正转和反转两个方向的锁定。

注意：过压和欠压故障需等待电压恢复正常后再清除。

## 九、CRC 校验

```c
static uint16_t Modbus_CalcCrc16(const uint8_t *pData, uint16_t len)
{
    uint16_t crc = 0xFFFFU;           // 1. 初始值
    uint16_t i, j;
    for (i = 0U; i < len; i++)        // 2. 遍历每个字节
    {
        crc ^= pData[i];              // 3. 当前字节与 CRC 异或
        for (j = 0U; j < 8U; j++)     // 4. 处理每个位（共 8 位）
        {
            if (crc & 0x0001U)        // 5. 检查最低位
            {
                crc >>= 1U;           // 6. 右移 1 位
                crc ^= 0xA001U;       // 7. 异或多项式
            }
            else
            {
                crc >>= 1U;           // 8. 仅右移
            }
        }
    }
    return crc;                       // 9. 返回结果
}
```

**算法流程：**

1. 初始化 CRC = 0xFFFF。
2. 对每个字节：CRC = CRC XOR 字节，重复 8 次：若 CRC 最低位为 1，则 CRC = (CRC >> 1) XOR 0xA001；否则 CRC = CRC >> 1。
3. 最终 CRC 即为校验值。
