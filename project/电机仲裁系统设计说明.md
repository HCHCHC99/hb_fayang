# 电机仲裁系统设计说明

## 一、核心模型：Allow/Block 四队列

电机仲裁系统维护 **4 个命令队列**，决定电机的最终运动方向：

```
MotorDevice_t:
  ├─ allow_fwd  (CommandList)  — 请求正转的设备，按优先级降序
  ├─ allow_rev  (CommandList)  — 请求反转的设备，按优先级降序
  ├─ block_fwd  (CommandList)  — 禁止正转的设备，无序追加
  └─ block_rev  (CommandList)  — 禁止反转的设备，无序追加
```

**规则**：某方向要转动，必须 **allow 非空 且 block 为空**。
- allow 是"请求"，block 是"安全锁"
- 安全锁优先级高于任何请求

---

## 二、仲裁决策算法（Motor_ArbitrationDecision）

```
1. 选命令:
   fwd_cmd = (block_fwd 为空 && allow_fwd 非空) ? allow_fwd[0] : NULL
   rev_cmd = (block_rev 为空 && allow_rev 非空) ? allow_rev[0] : NULL

2. 冲突判断:
   ┌─ fwd_cmd 和 rev_cmd 都有
   │   ├─ 同一设备ID → 冲突故障 → 不动
   │   ├─ fwd_cmd 优先级更高(值小) → 选 fwd_cmd
   │   ├─ rev_cmd 优先级更高(值小) → 选 rev_cmd
   │   └─ 同优先级 → 死锁 → 不动
   │
   └─ 只有一方 → 直接选中

3. 执行:
   ├─ 有选中 → Motor_OnArbitrationFwd() 或 Motor_OnArbitrationRev()
   └─ 无选中 → Motor_OnArbitrationStop()
```

**每 50ms 执行一次**（在 `Motor_Update` 中调用）。

---

## 三、命令队列操作

### SetAllow（加入允许请求）

```c
Motor_CmdList_SetAllow(allow_q, block_q, cmd)
```

1. **安全检查**：`block_q->count > 0` → **拒绝写入**（block 优先）
2. 移除 `allow_q` 中同 device_id 的旧命令
3. 按优先级降序插入（值越小优先级越高）
4. 触发仲裁

### SetBlock（加入阻塞锁）

```c
Motor_CmdList_SetBlock(block_q, cmd)
```

1. 去重：同 device_id 已存在 → 跳过
2. 追加到队尾（无序）
3. 触发仲裁

### Remove（移除命令）

```c
Motor_CmdList_Remove(queue, device_id)
```

查找并移除指定设备ID的命令，后续元素前移。

## 四、设备基因表（Device Gene Table）

每个设备有：唯一ID、优先级、能力（BLOCK/ALLOW/两者）。

| 设备ID | 名称 | 优先级 | 能力 | 说明 |
|--------|------|--------|------|------|
| DEV_ID_IO_FWD (6) | IO正转 | PRIO_MANUAL (3) | BLOCK \| ALLOW | 手动正转控制 |
| DEV_ID_IO_REV (7) | IO反转 | PRIO_MANUAL (3) | BLOCK \| ALLOW | 手动反转控制 |
| DEV_ID_RTURN_FWD (9) | 旋转限位正 | PRIO_LIMIT (2) | BLOCK | 正转限位保护 |
| DEV_ID_RTURN_REV (10) | 旋转限位反 | PRIO_LIMIT (2) | BLOCK | 反转限位保护（含关窗到位） |
| DEV_ID_OVERVOLTAGE_FWD (11) | 过压保护正 | PRIO_LIMIT (2) | BLOCK | 过压时阻塞正转 |
| DEV_ID_OVERVOLTAGE_REV (12) | 过压保护反 | PRIO_LIMIT (2) | BLOCK | 过压时阻塞反转 |
| DEV_ID_UNDERVOLTAGE_FWD (13) | 欠压保护正 | PRIO_LIMIT (2) | BLOCK | 欠压时阻塞正转 |
| DEV_ID_UNDERVOLTAGE_REV (14) | 欠压保护反 | PRIO_LIMIT (2) | BLOCK | 欠压时阻塞反转 |
| DEV_ID_OVERCUR_FWD (15) | 过流保护正 | PRIO_LIMIT (2) | BLOCK | 开窗过流故障 → 双向锁 |
| DEV_ID_OVERCUR_REV (16) | 过流保护反 | PRIO_LIMIT (2) | BLOCK | 关窗过流故障 → 双向锁 |

### 优先级体系

```
PRIO_EMERGENCY  = 0    最高（预留）
PRIO_LIMIT      = 2    限位、电压、过流保护
PRIO_MANUAL     = 3    手动IO控制
PRIO_CAN        = 4    CAN总线控制
PRIO_POWER      = 5    电源控制（双极性模式）
PRIO_NONE       = 255  无效
```

**值越小优先级越高**。

## 五、初始化状态

`Motor_Init` 中，IO 设备默认加入对应方向的 block：

```
初始化后:
  block_fwd = [DEV_ID_IO_FWD]    ← 正转默认锁定
  block_rev = [DEV_ID_IO_REV]    ← 反转默认锁定
  allow_fwd = []
  allow_rev = []
```

电机初始处于**双向锁定**状态，必须通过 IO 指令（FWD/REV）解除对应方向的 block 后才能转动。

---

## 六、IO 指令生命周期

### 正转指令（FWD）

```
用户发 FWD 指令
  └─ Motor_OnManualIO: type=RUN_FWD, dir=FWD
       ├─ Remove DEV_ID_IO_FWD from block_fwd  ← 解除初始锁
       ├─ SetAllow(&allow_fwd, &block_fwd, IO_FWD cmd)
       │    ├─ block_fwd 为空? → 是 → 通过
       │    └─ allow_fwd = [IO_FWD]
       └─ 触发仲裁 → fwd_cmd = IO_FWD → 电机正转 ✅
```

### 停止指令（STOP, dir=FWD）

```
用户发 STOP 指令
  └─ Motor_OnManualIO: type=STOP, dir=FWD
       ├─ Remove DEV_ID_IO_FWD from allow_fwd
       ├─ SetBlock(&block_fwd, IO_FWD block_cmd)
       │    └─ block_fwd = [IO_FWD]
       └─ 触发仲裁 → block_fwd 非空 → 停转 ✅
```

### 停止指令（STOP, dir=NONE / 急停）

```
用户发 急停 指令
  └─ Motor_OnManualIO: type=STOP, dir=NONE
       ├─ Remove IO_FWD from allow_fwd, Remove IO_REV from allow_rev
       ├─ SetBlock(&block_fwd, IO_FWD), SetBlock(&block_rev, IO_REV)
       └─ block_fwd = [IO_FWD], block_rev = [IO_REV] → 双向锁死
```

## 七、过流故障的双向熔断

过流故障触发时，同时封锁两个方向：

```
REV过流(角度异常) → SetFault(FAULT_BIT_OVERCURRENT_REV)
                  → TOPIC_OVERCURRENT_FWD(u8IsActive=1) → block_fwd += OVERCUR_FWD
                  → TOPIC_OVERCURRENT_REV(u8IsActive=1) → block_rev += OVERCUR_REV
                  → 双向锁死

清除故障(485指令)
  → ClearFault(FWD | REV)
  → TOPIC_OVERCURRENT_FWD(u8IsActive=0) → 移除 block_fwd 的 OVERCUR_FWD
  → TOPIC_OVERCURRENT_REV(u8IsActive=0) → 移除 block_rev 的 OVERCUR_REV
  → 双向解锁
```

> 注意：关窗过流且角度在[0x272A, 0x2729]校准范围内 → 执行校准，不触发故障位，仅单向锁反转方向。

## 八、block 队列的典型状态

| 场景 | block_fwd | block_rev | 电机状态 |
|------|-----------|-----------|---------|
| 上电初始化 | IO_FWD | IO_REV | 不动 |
| IO 正转中 | 空 | IO_REV | 正转 |
| IO 反转中 | IO_FWD | 空 | 反转 |
| 急停 | IO_FWD | IO_REV | 不动 |
| 关窗到位(正常) | IO_FWD | RTURN_REV | 反转锁定，正转可动 |
| 开窗过流故障 | IO_FWD + OVERCUR_FWD + RTURN_FWD | OVERCUR_REV + IO_REV | 双向锁死 |
| 关窗过流故障 | OVERCUR_FWD + IO_FWD | IO_REV + OVERCUR_REV + RTURN_REV | 双向锁死 |
| 清除故障后 | IO_FWD | IO_REV | 恢复到初始化状态 |

---

## 九、关键设计原则

1. **安全优先**：block 优先级高于 allow，任何时候 block 都能否决运动
2. **互斥约束**：block 和 allow 永远不会同时非空（SetAllow 拒绝 / SetBlock 清空）
3. **故障双向熔断**：任一方向过流故障 → 两个方向全锁，确保故障态下电机完全不可动
4. **方向锁不影响另一方向**：RTurn 限位锁只锁单个方向，不影响反方向运动
5. **IO 设备默认阻塞**：初始化和急停时 IO 设备默认 block，防止误动作
