## 三、控制命令（不存 Flash）

写路径: `Param_WriteByReg()` 直接处理，不存 Flash

| 地址 | 名称 | R/W | 类型 | 说明 |
|------|------|-----|------|------|
| 0x2720 | REG_CTRL_CMD | R/W | uint16 | 控制命令寄存器 |

### 0x2720 位定义

| 位 | 宏 | 值 | 说明 |
|----|-----|------|------|
| bit0 | CTRL_CMD_START | 0x0001 | 解锁（控制开启），允许 bit3~bit5 |
| bit1 | CTRL_CMD_STOP | 0x0002 | 上锁（控制关闭），禁止 bit3~bit5 |
| bit2 | CTRL_CMD_ESTOP | 0x0004 | 急停，无条件执行 |
| bit3 | -- | 0x0008 | 延时复位 |
| bit4 | CTRL_CMD_FWD | 0x0010 | 正转/开窗 |
| bit5 | CTRL_CMD_REV | 0x0020 | 反转/关窗 |

**读回**: bit4=1 正在正转, bit5=1 正在反转, bit4=bit5=0 停止

**操作流程**:
```
解锁 → 发 FWD/REV → 操作完毕 → 上锁
0x0001    0x0010/0x0020            0x0002
```

## 四、关窗基准点（独立 Flash 扇区 55）

| 地址 | 名称 | R/W | 类型 | 说明 |
|------|------|-----|------|------|
| 0x2721 | REG_ABS_ANGLE_LO | R | int32 低16位 | RAM 实时偏移 (0.1°) |
| 0x2722 | REG_ABS_ANGLE_HI | R | int32 高16位 | |
| 0x2723 | REG_FLASH_ABS_LO | R | int32 低16位 | Flash 已保存偏移 (0.1°) |
| 0x2724 | REG_FLASH_ABS_HI | R | int32 高16位 | |
| 0x2725 | REG_ABS_CMD | W | uint16 | 命令寄存器 |
| 0x2726 | REG_ABS_THRESHOLD | R/W | uint16 | 停止阈值 0.1° (默认1, 范围0~200) |
| 0x2727 | REG_ABS_TARGET_LO | R/W | int32 低16位 | 目标角度 (0.1°) |
| 0x2728 | REG_ABS_TARGET_HI | R/W | int32 高16位 | 0x10连续写0x2727+0x2728即触发回目标 |

### 0x2725 命令

| 值 | 操作 | 说明 |
|----|------|------|
| 0x0000 | 设基准点并保存 | RAM = Flash = 0x271C值 |
| 0x0001 | 回关窗基准点 | 转到 0x271C 定义的角度；⚠需解锁+停转 |
| 0x0002 | 保存到 Flash | Flash = RAM |
| 0x0003 | 设基准点 | 同 0x0000 |

### 0x2727/0x2728 目标角度

- **写**: `01 10 27 27 00 02 04 LO_H LO_L HI_H HI_L CRC CRC` → 存 int32 + 触发回目标
- **读**: `01 03 27 27 00 02` → 返回 4 字节 int32
- 回目标同样经过解锁+停转门禁，到达阈值内后 ESTOP

## 六、故障状态

| 地址 | 名称 | R/W | 类型 | 说明 |
|------|------|-----|------|------|
| 0x2740 | REG_FAULT_STATUS | R/W | uint16 | 故障状态位 |

### 故障位定义

| 位 | 宏 | 值 | 说明 |
|----|-----|------|------|
| bit0 | FAULT_BIT_OVERVOLTAGE | 0x0001 | 过压 |
| bit1 | FAULT_BIT_OVERCURRENT_FWD | 0x0002 | **正转(开窗)过流故障** |
| bit2 | FAULT_BIT_OVERCURRENT_REV | 0x0004 | **反转(关窗)过流故障** |
| bit6 | FAULT_BIT_UNDERVOLTAGE | 0x0040 | 欠压（触发时自动保存绝对角度） |
| bit3 | FAULT_BIT_RESET | 0x0008 | 复位 |
| bit4 | FAULT_BIT_OVERLOAD | 0x0010 | 过载 |
| bit5 | FAULT_BIT_STALL | 0x0020 | 堵转 |

### 双向熔断机制

任何方向发生过流故障时，电机**双向锁死**：
- 正转(开窗)过流 → set bit1 → block_fwd + block_rev 同时阻塞
- 反转(关窗)过流(角度异常) → set bit2 → block_fwd + block_rev 同时阻塞

**清除故障**（写 0x2740 bit2=1）会自动：
- 清除 bit1 + bit2 两个故障位
- 解除 block_fwd 和 block_rev 两个方向的过流锁

> **注意**：关窗过流但角度在[0x272A, 0x2729]校准范围内 → 执行校准，**不触发故障位**，仅单向锁反转方向。

## 九、写路径对比

| 写入目标 | Modbus 指令 | 固件写路径 | Flash |
|----------|------------|-----------|-------|
| 0x2710~0x271E | `01 06 27 XX` | Param_WriteByReg → 校验 → Param_Save | ✅ 62-56 |
| 0x2720 | `01 06 27 20` | Param_WriteByReg 直接处理 | ❌ |
| 0x2725 | `01 06 27 25` | App_Modbus 拦截 → RunAngle_Cmd | 部分 ✅55 |
| 0x2726 | `01 06 27 26` | App_Modbus 拦截 → RunAngle_SetThreshold | ✅ 55 |
| 0x2727(单) | `01 06 27 27` | Param_WriteByReg → 存 int32 LO（不触发） | ❌ |
| 0x2728(单) | `01 06 27 28` | Param_WriteByReg → 存 int32 HI（不触发） | ❌ |
| 0x2727+0x2728 | `01 10 27 27 00 02 04 ...` | Param_WriteByReg x2 → 结束后 RunAngle_GotoTarget | ❌ |
| 0x2729 | `01 06 27 29` | Param_WriteByReg → 校验 → Param_Save | ✅ 62-56 |
| 0x272A | `01 06 27 2A` | Param_WriteByReg → 校验 → Param_Save | ✅ 62-56 |
| 0x3710~0x3713 | `01 06 37 XX` | Param_WriteByReg → 直接写入 | ❌ |
| 0x2740 | `01 06 27 40` | Param_WriteByReg → 故障处理 → 跳过 Flash | ❌ |
| 0x2740 (清过流故障) | `01 06 27 40 00 04` | FaultHandler_ClearFault → 清双向故障位 + 双向释放 | ❌ |
